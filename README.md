# Brillio listing search assessment

Full-stack take-home for Brillio Software Engineer hiring: search property listings from multiple MLS feeds through a React UI backed by a small API (Python, Go, or Java).

This repo is **private**. The handout asks for individual work and a zip of the finished project, not a public solution.
